# KAISER Interactive Video Studio

ระบบวิดีโอแบบมีปฏิสัมพันธ์สำเร็จรูป **ไม่ต้องมี Moodle** ผู้สอนอัปโหลดวิดีโอแล้วใส่คำถามลงบนวิดีโอ
ผู้เรียนดูและตอบ ผู้สอนดูคะแนน ทั้งหมดรันด้วย Docker คำสั่งเดียว

- คำถาม 10 ชนิด: ตอบข้อเดียว, ตอบหลายข้อ, ถูกหรือผิด, พิมพ์คำตอบ, เติมคำ, ลากคำไปเติม,
  เลือกคำในข้อความ, ข้อความ, รูปภาพ, ลิงก์
- วิดีโอหยุดที่คำถาม และข้ามคำถามไปไม่ได้
- **เฉลยไม่เคยถูกส่งไปที่เบราว์เซอร์** การตรวจทั้งหมดทำที่เครื่องยนต์ฝั่งเซิร์ฟเวอร์
- ผู้ใช้ 3 บทบาท: ผู้ดูแลระบบ, ผู้สอน, ผู้เรียน

---

## สิ่งที่ต้องมี

- เครื่องที่รัน **Docker** และ **Docker Compose** ได้ (Linux, Windows หรือ macOS)
- พื้นที่ดิสก์พอสำหรับวิดีโอที่จะอัปโหลด

ไม่ต้องมีฐานข้อมูลแยก ไม่ต้องมี Moodle ไม่ต้องต่ออินเทอร์เน็ตหลังติดตั้งเสร็จ
(ยกเว้นบทเรียนที่ใช้วิดีโอจาก YouTube หรือ Vimeo)

---

## ติดตั้ง

**1. แตกไฟล์** `kaiiv-studio-<เวอร์ชัน>.zip` จะได้โฟลเดอร์ `kaiiv-studio-<เวอร์ชัน>`
ที่มี `kaiiv-studio/` (ตัวระบบ), `kaiiv-service/` (เครื่องยนต์) และ `kaiiv-player/` (ตัวเล่น)
**ต้องอยู่ด้วยกันครบทั้งสาม** แล้วเข้าไปที่ `kaiiv-studio`

```bash
cd kaiiv-studio-1.0.0/kaiiv-studio
```

**2. ตั้งค่า** คัดลอก `env.example` เป็น `.env` แล้วใส่ค่า 3 ช่อง

```bash
cp env.example .env
```

| ค่า | ใส่อะไร |
|---|---|
| `KAIIV_API_KEY` | ข้อความสุ่มยาวๆ (กุญแจระหว่างระบบกับเครื่องยนต์) |
| `KAIIV_STUDIO_SECRET` | ข้อความสุ่มยาวๆ อีกชุด **ห้ามซ้ำกับข้างบน** |
| `KAIIV_ADMIN_PASSWORD` | รหัสผ่านของผู้ดูแลระบบคนแรก อย่างน้อย 10 ตัวอักษร มีตัวพิมพ์เล็ก ตัวพิมพ์ใหญ่ และตัวเลข |

สร้างข้อความสุ่มได้ด้วย

```bash
python3 -c "import secrets; print(secrets.token_urlsafe(32))"
```

**3. เริ่มระบบ**

```bash
docker compose up -d --build
```

**4. เปิด** http://127.0.0.1:8300 แล้วเข้าสู่ระบบด้วย `admin` และรหัสผ่านจากขั้นที่ 2
เปลี่ยนรหัสผ่านทันทีที่เมนูชื่อของคุณมุมขวาบน จากนั้นจะลบ `KAIIV_ADMIN_PASSWORD` ออกจาก `.env` ก็ได้
(ใช้ครั้งเดียวตอนเริ่มครั้งแรกเท่านั้น)

## ใช้งาน

1. **ผู้ดูแลระบบ** → เมนู "ผู้ใช้" → เพิ่มผู้สอนและผู้เรียน
2. **ผู้สอน** → "สร้างบทเรียน" → ใส่ชื่อ อัปโหลดวิดีโอ (MP4 หรือ WebM) หรือใส่ลิงก์ YouTube / Vimeo
3. หน้า "คำถาม" → เล่นวิดีโอไปจุดที่ต้องการ กด **"ใช้เวลาตอนนี้"** เลือกชนิด กรอก แล้ว "บันทึก"
4. ติ๊ก **"เปิดให้ผู้เรียนเห็น"** ที่หน้า "ตั้งค่า" เมื่อพร้อม
5. **ผู้เรียน** เข้าสู่ระบบ เลือกบทเรียน ดูและตอบ
6. **ผู้สอน** → "คะแนน" ดูรายคน รายข้อ และดาวน์โหลด CSV

วิธีเขียนคำตอบในช่องที่มีดอกจัน:

| ชนิด | เขียนแบบนี้ |
|---|---|
| เติมคำ / ลากคำไปเติม | `เมืองหลวงของ *ฝรั่งเศส* คือปารีส` — หลายคำที่รับได้ใช้ `/` เช่น `*เวกเตอร์/vector*` |
| เลือกคำในข้อความ | `ระบบบันทึก *เหตุการณ์* และ *เวลา*` |
| พิมพ์คำตอบ | คำตอบที่รับได้ บรรทัดละคำ |

## ใช้งานจริงกับเครื่องอื่นในองค์กร

ค่าเริ่มต้นเปิดให้เข้าได้จากเครื่องนี้เท่านั้น (`127.0.0.1`) ถ้าจะให้เครื่องอื่นเข้า:

- **แนะนำ**: วาง reverse proxy ที่มี HTTPS ไว้ข้างหน้า (เช่น Caddy, Nginx) ชี้มาที่ `127.0.0.1:8300`
  แล้วตั้ง `KAIIV_SECURE_COOKIES=1` ใน `.env`
- หรือเปิดในเครือข่ายภายในเท่านั้น: ตั้ง `KAIIV_BIND` เป็น IP ภายในของเครื่อง

**ห้ามเปิดพอร์ตของเครื่องยนต์ (`kaiiv-service`)** ไฟล์ compose ไม่ได้เปิดไว้ และต้องคงไว้แบบนั้น

## สำรองข้อมูล

ข้อมูลทั้งหมด (ฐานข้อมูลและวิดีโอที่อัปโหลด) อยู่ใน volume `studio-data` เครื่องยนต์ไม่เก็บอะไรเลย

```bash
docker compose cp studio:/data ./backup-studio
```

กู้คืน: หยุดระบบ แล้วคัดลอกกลับ

```bash
docker compose stop studio
```

```bash
docker compose cp ./backup-studio/. studio:/data
```

```bash
docker compose start studio
```

แล้วคืนสิทธิ์ของไฟล์ให้ระบบ — `docker compose cp` เขียนไฟล์เป็นของ root
ถ้าข้ามขั้นนี้ ระบบจะเปิดได้แต่**บันทึกอะไรไม่ได้เลย** (ฐานข้อมูลกลายเป็นอ่านอย่างเดียว)

```bash
docker compose exec -u root studio chown -R studio:studio /data
```

## อัปเดตเป็นเวอร์ชันใหม่

แตกไฟล์ ZIP ใหม่ทับโฟลเดอร์เดิม (เก็บ `.env` ไว้) แล้วรัน `docker compose up -d --build`
ข้อมูลใน volume อยู่ครบ **สำรองข้อมูลก่อนทุกครั้ง**

## ปัญหาที่พบบ่อย

| อาการ | แก้ |
|---|---|
| หน้าเข้าสู่ระบบขึ้นว่า "ยังไม่มีผู้ใช้ในระบบ" | ยังไม่ได้ตั้ง `KAIIV_ADMIN_PASSWORD` หรือรหัสผ่านไม่ผ่านเกณฑ์ ดู `docker compose logs studio` |
| "ติดต่อเครื่องยนต์ตรวจคำตอบไม่ได้" | `docker compose ps` ดูว่า `kaiiv-service` ยัง healthy อยู่ ผู้สอนจะเห็นสาเหตุใต้ข้อความ |
| อัปโหลดแล้วขึ้นว่า "ไฟล์นี้ไม่ใช่วิดีโอ" | ใช้ไฟล์ MP4 (H.264) หรือ WebM ไฟล์อื่นที่แค่เปลี่ยนนามสกุลจะถูกปฏิเสธ |
| ไฟล์ใหญ่เกิน | ปรับ `KAIIV_MAX_UPLOAD_MB` ใน `.env` (ค่าเริ่มต้น 1024) และที่ reverse proxy ถ้ามี |
| ลองเข้าสู่ระบบผิดหลายครั้งแล้วเข้าไม่ได้ | รอ 15 นาที หรือให้ผู้ดูแลระบบตั้งรหัสผ่านใหม่ให้ |

## ขอบเขตการทดสอบ

ทดสอบแล้วในเบราว์เซอร์จริง (Chromium) บน Docker ตั้งแต่ติดตั้งใหม่:
ผู้ดูแลระบบเพิ่มผู้ใช้ ผู้สอนอัปโหลดวิดีโอและสร้างคำถามครบ 10 ชนิดผ่านหน้าจอ ผู้เรียนตอบได้ครบ
คะแนนขึ้นในรายงาน และมีชุดทดสอบอัตโนมัติ 31 ข้อที่รันกับเครื่องยนต์ตัวจริง
(สิทธิ์ตามบทบาท, เฉลยไม่หลุด, ตอบซ้ำหลังหมดสิทธิ์ไม่ได้, ข้อความที่ผู้สอนพิมพ์รันเป็นสคริปต์ไม่ได้)

**ยังไม่ได้ทดสอบ**: วิดีโอจาก YouTube, Vimeo และ HLS · Safari และ Firefox · มือถือจริง ·
ผู้ใช้พร้อมกันจำนวนมาก (SQLite เหมาะกับองค์กรขนาดเล็กถึงกลาง)
