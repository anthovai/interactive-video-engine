# ติดตั้งวิดีโอแบบมีปฏิสัมพันธ์ (KAISER)

คู่มือนี้สำหรับผู้ดูแลระบบ Moodle ที่จะติดตั้งกิจกรรมนี้เอง

ระบบมีสองส่วน และ**ต้องมีครบทั้งคู่**

| ส่วน | ไฟล์ | ทำหน้าที่ |
|---|---|---|
| ปลั๊กอิน Moodle | `mod_kaiiv-<เวอร์ชัน>.zip` | ตัวกิจกรรม ตัวเล่นวิดีโอ หน้าสร้างคำถาม รายงาน |
| เครื่องยนต์ | `kaiiv-service-<เวอร์ชัน>.zip` | ตรวจคำตอบ และกันไม่ให้เฉลยไปถึงเบราว์เซอร์ |

เฉลยเก็บอยู่ใน Moodle แต่การตัดสินว่าตอบถูกหรือไม่เกิดที่เครื่องยนต์เท่านั้น
**ถ้าเครื่องยนต์ไม่ทำงาน กิจกรรมจะแสดงข้อความแจ้งแทนวิดีโอ** โดยตั้งใจ — วิดีโอที่เล่นได้
แต่คำถามหายไปเงียบๆ จะทำให้ผู้เรียนจบกิจกรรมโดยไม่มีใครได้ประเมินเลย

---

## สิ่งที่ต้องมี

- Moodle **4.5 ขึ้นไป** (ทดสอบแล้วบน Moodle 5.1)
- เครื่องที่รัน **Docker** ได้ และ Moodle เชื่อมต่อถึงผ่านเครือข่าย จะเป็นเครื่องเดียวกับ Moodle ก็ได้
- สิทธิ์ผู้ดูแลระบบของ Moodle

---

## 0. สำรองข้อมูลก่อน

สำรองฐานข้อมูลและโฟลเดอร์ `moodledata` ก่อนติดตั้งปลั๊กอินใดๆ บนระบบจริง
การอัปเกรดฐานข้อมูลของ Moodle ย้อนกลับไม่ได้

---

## 1. เปิดเครื่องยนต์

แตกไฟล์ `kaiiv-service-<เวอร์ชัน>.zip` บนเครื่องที่จะรัน แล้วตั้งกุญแจเป็นข้อความสุ่มยาวๆ
(เก็บไว้ ต้องใช้อีกครั้งในขั้นที่ 3)

```bash
cd kaiiv-service
```

```bash
KAIIV_API_KEY=<กุญแจของคุณ> docker compose up -d --build
```

ตรวจว่าทำงาน ต้องได้ `"ok":true`

```bash
curl http://127.0.0.1:9200/health
```

**เครื่องยนต์ต้องเข้าถึงจากอินเทอร์เน็ตไม่ได้** ค่าเริ่มต้นผูกไว้กับ `127.0.0.1` ซึ่งถูกต้องเมื่อ
Moodle อยู่บนเครื่องเดียวกัน ถ้า Moodle อยู่คนละเครื่อง ให้ผูกกับ IP ภายในของเครือข่ายนั้น
แล้วเปิด firewall ให้เฉพาะเครื่อง Moodle:

```bash
KAIIV_BIND=10.0.0.5 KAIIV_API_KEY=<กุญแจของคุณ> docker compose up -d --build
```

**ถ้า Moodle เองรันอยู่ใน Docker** ที่อยู่ `127.0.0.1` จะใช้ไม่ได้ เพราะในคอนเทนเนอร์ของ Moodle
`127.0.0.1` คือตัวคอนเทนเนอร์ Moodle เอง ไม่ใช่เครื่องที่รันเครื่องยนต์ ให้ต่อเครื่องยนต์เข้า
network เดียวกับ Moodle แทน (ดูชื่อ network ได้จาก `docker network ls`)

```bash
docker network connect --alias kaiiv-service <network ของ Moodle> kaiiv-service-kaiiv-service-1
```

แล้วในขั้นที่ 3 ใช้ที่อยู่ `http://kaiiv-service:9200` คำสั่งนี้ต้องรันใหม่ทุกครั้งที่สร้างคอนเทนเนอร์
เครื่องยนต์ใหม่ (`docker compose up --build`)

เครื่องยนต์ไม่เก็บข้อมูลใดๆ คำตอบทุกข้ออยู่ใน Moodle จึงหยุด build ใหม่ หรือย้ายเครื่องได้ตลอด
โดยไม่มีอะไรหาย

## 2. ติดตั้งปลั๊กอิน

**ทางที่ 1 — ผ่านหน้าเว็บ** (ง่ายที่สุด)

การจัดการระบบ → ปลั๊กอิน → ติดตั้งปลั๊กอิน
(Site administration → Plugins → Install plugins)
แล้วอัปโหลด `mod_kaiiv-<เวอร์ชัน>.zip` → ตรวจสอบ → ติดตั้ง → อัปเกรดฐานข้อมูล

ถ้าไม่มีเมนูนี้ หรือขึ้นว่าเขียนไฟล์ไม่ได้ แปลว่าเว็บไซต์ปิดการติดตั้งผ่านหน้าเว็บไว้
(พบบ่อยเมื่อรัน Moodle ใน Docker) ให้ใช้ทางที่ 2

**ทางที่ 2 — วางไฟล์เอง**

แตกไฟล์ ZIP จะได้โฟลเดอร์ชื่อ `kaiiv` วางไว้ที่

| เวอร์ชัน Moodle | ที่อยู่ |
|---|---|
| 5.0 ขึ้นไป | `<moodle>/public/mod/kaiiv` |
| 4.5 | `<moodle>/mod/kaiiv` |

แล้วรัน (หรือเข้าหน้าการจัดการระบบ Moodle จะถามให้อัปเกรดเอง)

```bash
php admin/cli/upgrade.php
```

ชื่อโฟลเดอร์ต้องเป็น `kaiiv` เท่านั้น ไม่ใช่ `mod_kaiiv` — Moodle จะไม่รู้จักถ้าชื่อไม่ตรง

---

## 3. ตั้งค่า

การจัดการระบบ → ปลั๊กอิน → โมดูลกิจกรรม → วิดีโอแบบมีปฏิสัมพันธ์ (KAISER)

| ช่อง | ใส่อะไร |
|---|---|
| ที่อยู่ของเครื่องยนต์ | เช่น `http://127.0.0.1:9200`, `http://10.0.0.5:9200` หรือ `http://kaiiv-service:9200` เมื่อ Moodle รันใน Docker |
| กุญแจของเครื่องยนต์ | กุญแจเดียวกับที่ใช้ในขั้นที่ 1 |

ถ้าเว็บไซต์ติดตั้ง **KAISER Proctor** อยู่แล้ว ปล่อยสองช่องนี้ว่าง ระบบจะใช้ค่าจาก KAISER Proctor
และเลือกเปิดการเฝ้าดูระหว่างเรียนให้กิจกรรมนี้ได้เหมือนกิจกรรมวิดีโออื่น (ยังไม่ได้ทดสอบ ดูหัวข้อ "ขอบเขตการทดสอบ")

---

## 4. ตรวจก่อนใช้จริง

1. สร้างคอร์สทดลองที่ไม่มีผู้เรียนจริง
2. เพิ่มกิจกรรม "วิดีโอแบบมีปฏิสัมพันธ์ (KAISER)" ใส่ไฟล์ MP4
3. เปิดเมนู "สิ่งที่อยู่บนไทม์ไลน์" เพิ่มคำถามแบบ "ตอบข้อเดียว" ที่วินาทีที่ 3
4. เข้าเป็นผู้เรียนทดลอง กดเล่น

ต้องเห็นวิดีโอหยุดที่วินาทีที่ 3 มีคำถามขึ้นทับภาพ ตอบแล้วขึ้นผลว่าถูกหรือผิด และกด "เล่นต่อ" ได้
ถ้าได้ตามนี้ครบ จึงเริ่มใช้ในคอร์สจริง

---

## ปัญหาที่พบบ่อย

ผู้เรียนจะเห็นข้อความ "ติดต่อเครื่องยนต์ไม่ได้" เหมือนกันทุกกรณี ส่วน**ผู้สอนและผู้ดูแลระบบ**
จะเห็นสาเหตุจริงเพิ่มใต้ข้อความนั้น:

| สาเหตุที่เห็น | แปลว่า | แก้ |
|---|---|---|
| unreachable | Moodle เชื่อมต่อถึงเครื่องยนต์ไม่ได้ | ตรวจที่อยู่ในขั้นที่ 3, firewall และ `docker compose ps` ว่ายังรันอยู่ ถ้า Moodle รันใน Docker และใส่ `127.0.0.1` ไว้ ดูวิธีแก้ท้ายขั้นที่ 1 ถ้ายังไม่ได้ตั้งที่อยู่ ระบบจะลอง `http://kaiiv-service:9200` |
| เครื่องยนต์ปฏิเสธกุญแจของเรา | กุญแจสองฝั่งไม่ตรงกัน | ใส่กุญแจเดียวกับ `KAIIV_API_KEY` |
| ปุ่มในตัวเล่นเป็นสี่เหลี่ยมว่าง หรือหน้าตาเพี้ยน | แคชของธีมยังเป็นของเก่า | การจัดการระบบ → การพัฒนา → ล้างแคชทั้งหมด |

## ขอบเขตการทดสอบ

แจ้งไว้เพื่อให้วางแผนได้ถูก:

ทดสอบแล้วบน Moodle 5.1 ใหม่ที่ไม่มีปลั๊กอินอื่นของ KAISER ตามคู่มือนี้ทุกขั้น: ติดตั้งและอัปเกรด
ผ่านหน้าเว็บ ตั้งค่า อัปโหลดไฟล์ MP4 ผู้สอนสร้างคำถามครบทั้ง 10 ชนิดผ่านฟอร์ม ผู้เรียนตอบได้ครบ
คะแนนเข้าสมุดคะแนน และข้อความเมื่อเครื่องยนต์ใช้งานไม่ได้แสดงถูกต้อง

ยังไม่ได้ทดสอบ:

- **วิดีโอจาก YouTube, Vimeo และสตรีม HLS** กับกิจกรรมนี้
- **Moodle 4.5** (ทดสอบบน 5.1 เท่านั้น)
- **การเฝ้าดูระหว่างเรียนของ KAISER Proctor** กับกิจกรรมนี้
- **จอมือถือ**
