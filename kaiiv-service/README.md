# kaiiv-service — เครื่องยนต์ของวิดีโอแบบมีปฏิสัมพันธ์

ตรวจคำตอบให้ปลั๊กอิน Moodle `mod_kaiiv` และกันไม่ให้เฉลยไปถึงเบราว์เซอร์
ไม่เก็บข้อมูลใดๆ — คำตอบทุกข้ออยู่ใน Moodle

```bash
KAIIV_API_KEY=<กุญแจยาวๆ> docker compose up -d --build
```

```bash
curl http://127.0.0.1:9200/health
```

ขั้นตอนติดตั้งทั้งหมด รวมถึงการผูกกับเครือข่ายภายในเมื่อ Moodle อยู่คนละเครื่อง
อยู่ใน `INSTALL.md` ที่มากับปลั๊กอิน (`mod_kaiiv-<เวอร์ชัน>.zip`)

**ห้ามเปิดให้เข้าถึงจากอินเทอร์เน็ต** เบราว์เซอร์ที่เข้าถึงเครื่องยนต์ได้ คือเบราว์เซอร์ที่สั่งให้มันตรวจคำตอบได้
